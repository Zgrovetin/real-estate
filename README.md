# Real Estate Platform

A full-stack Single Page Application (SPA) for buying and selling real estate properties with advanced features for property management and offer handling.

## 🏠 Features

- **Property Listings**: Browse and manage real estate listings with detailed information
- **Monthly Payment Simulation**: Calculate and simulate monthly payment plans for properties
- **Offer Management**: Create, submit, and manage property offers
- **Listing Management**: Add, edit, and manage property listings
- **Image Management**: Upload and manage multiple images for properties
- **Offer Tracking**: Browse and accept offers on your properties
- **Event Notifications**: Receive real-time notifications for property-related events
- **Email Integration**: Automated email notifications for offers and updates

## 🚀 Tech Stack

### Backend
- **PHP/Laravel**: Server-side application framework
- **Composer**: PHP dependency management

### Frontend
- **Vue.js**: Modern JavaScript framework for the SPA
- **Tailwind CSS**: Utility-first CSS framework for styling
- **Vite**: Next-generation frontend tooling

### Database & Infrastructure
- **Docker**: Containerized development environment
- **Node.js**: JavaScript runtime for build tools (v18 via .nvmrc)
- **npm**: Node package manager

## 📋 Prerequisites

- PHP 8.x
- Node.js (see `.nvmrc` for version)
- Composer
- Docker & Docker Compose (optional)
